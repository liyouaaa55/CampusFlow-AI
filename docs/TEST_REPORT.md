## 六、暴露的系统问题

### P0-1 任务状态信息 100% 丢失，存量台账无法承接

- 现象：隐患整改台账（整改中/未开始/已完成）、运动会任务一览表（已完成 3 / 进行中 5 / 待办 9 / 延期 1）导入后全部变成 `pending`
- 根因：`llm/prompts.py` 第 30 行强制 `status 固定返回 "pending"`，识别阶段无状态入口
- 影响：无法承接学校既有台账、无法增量更新、驾驶舱状态统计失真，与「闭环执行」主张冲突

### P0-2 进展通报类材料产生严重幻觉（12 条）

材料原文全是「已完工/已批复/已划定/正在实施」的已完成或进行中内容，系统重新生成为 12 条待办：

- 「宣传工作总体方案和《宣传用语手册》**已完成初稿**」→ 生成「完成运动会宣传方案初稿」
- 「保卫处**已划定**封闭区域和疏散通道」→ 生成「完成运动会安全区域划定」
- 「12 个二级学院中**已有 8 个完成**报名汇总与资格审核」→ 生成「完成运动会报名汇总与资格审核」

附带问题：杜撰部门——「报名汇总与资格审核」被标为「教务处」，原文实为体育教学部。

根因：Prompt 未要求判别材料时态，也未显式要求「若材料不产生新事项则返回空数组」。这类材料（周报、进展通报）在高校极常见，误用会直接派发虚假任务。

### P1-1 责任部门被知识库污染（已用对照实验定位根因）

同一材料、同一模型，仅切换知识库开关：

| 材料 | 注入知识库（现状） | 禁用知识库 |
| --- | --- | --- |
| 学生事务台账 | 4 条有部门（全为「学工办」）+ **6 条丢失为 null** | **10 条全部准确** |
| 毕业生就业工作安排 | 1 条有部门 + **4 条丢失为 null** | **5 条全部准确** |
| Word 会议纪要 | 学工办 | 学生工作办公室（忠实原文） |

- 根因：`knowledge/organization/departments.json` 只有 7 个部门的**闭集**，别名映射把「学生工作办公室 / 学生工作部 / 学工部」统一压成「学工办」，未收录单位（各二级学院、就业指导中心等）被模型判定为「不可用」而输出 null
- 连带影响：驾驶舱部门维度统计失真——TOP1「学工办」16 条，实为多个不同单位被合并
- **结论：知识库注入在本场景下收益为负**，建议改为「原文优先，知识库仅作可选建议」

### P1-2 上传 Office 临时锁文件会导致应用崩溃

- 资料目录中存在 13 个 `~$` 开头的 Office 临时锁文件（如 `~$rd 格式会议纪要.docx`），扩展名合法，会通过 `ui/pages/upload_page.py` 的 `ALLOWED_TYPES` 过滤
- 上传 `.docx` 锁文件 → `python-docx` 抛 `PackageNotFoundError`
- 该异常**不在** `upload_page.py` 第 126 行捕获列表（`LLMError / ValueError / FileNotFoundError / ImportError / KnowledgeError`）中 → Streamlit 崩溃并显示完整 traceback，**暴露本机文件路径**
- 上传 `.xlsx` 锁文件 → 被兜底捕获，但提示「请确认文件未加密、未损坏」，**误导用户去折腾密码**

## 七、改进建议（按投入产出比排序）

1. **给 Prompt 增加时态判别约束**（P0-2，改动最小、收益最大）
   在 `TASK_EXTRACTION_SYSTEM` 的「抽取原则」补两条：「材料中已明确『已完成/已批复/已划定/正在实施』的内容不构成新事项」；「若通篇为已完成或推进中情况、无新增待办事项，返回 `[]`」，并补一个少样本示例。
2. **开放 status 入口**（P0-1）
   `status` 从固定 `pending` 改为「文本中明确出现则映射，未提及返回 null」。映射：已完成→`completed`，进行中/整改中→`processing`，待办/未开始→`pending`，延期→保留原描述。
3. **知识库改为可选建议**（P1-1）
   约束从「只能取自」改为「原文出现的部门名称优先，以下仅为口径参考」；扩充 `departments.json`（补保卫处、安全工作处、国有资产管理处、就业指导中心、各二级学院等层级）。
4. **上传链路加文件名白名单**（P1-2，成本极低）
   `parse_file()` 开头拒绝 `~$`、`.~` 开头的文件名并给出明确提示；`upload_page.py` 异常捕获补 `Exception` 兜底。
5. **补齐测试用例**（配合 P0-1、P0-2）
   `tests/test_task_agent.py` 增加「进展通报类材料应返回空」「Excel 状态列应被识别」两组用例。
